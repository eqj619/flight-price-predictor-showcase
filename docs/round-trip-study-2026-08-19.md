# 往復に片道の曲線を当てはめてよいか — 観測計画（2026-08-19 開始）

段階C。**判定（買い時）を往復に出す前に、これを測る。**

## 何が分かっていないか

片道の曲線は 212系列 / 13,004点から推定した（`price-curve-2026-08-15.md`）。

| 50–59日前の谷 | −4.2%（29/40系列, z=+2.8） |
|---|---|
| 出発30日前以降 | **+16.7%**（35/41系列, z=+4.5） |

**この曲線が往復にも当てはまる保証は無い。** そして往復には片道に無い次元が
ある — **滞在日数**。7泊と14泊で形が違うなら、`sweet_spot` を滞在日数で
変える必要がある。

未検証の曲線で判定を出すのは課題2で一度やった失敗なので、繰り返さない。

## 設計

```
区間   SAN-HND / SAN-NRT / LAX-HND / LAX-NRT
出発日 2026-11-15 〜 2027-02-13 を等間隔に10日付（88〜178日後）
滞在   7泊 / 10泊 / 14泊
合計   4 × 10 × 3 = 120 ルート（各滞在40本）
```

**出発日の範囲は片道調査（2026-08-17開始）と同一にした。** 端は
2026-11-15 と 2027-02-13 で一致する。SAN-HND と SAN-NRT は両方の調査に
あるので、**同じ区間・ほぼ同じ出発日で片道と往復を突き合わせられる。**

**滞在日数を3通りにしたのは、曜日の効果と長さの効果を分けるため。**
7泊と14泊は7の倍数なので復路の曜日が出発と同じになり、長さだけが変わる。
10泊はそれを崩すので、復路の曜日が効くかどうかが見える。

**近接空港ルールは使わない。** 狙った区間だけを観測する。

## 何がいつ分かるか

**履歴が往復でも取れる**（62点/60日分、2026-08-19 実測）ので、**収集開始を
待たずに測れる。** 片道のときと同じ手が使える。

| いま（遡り取り込み直後） | 過去60日ぶんで、出発88〜238日前あたりの形 |
|---|---|
| 2026-11-15 | 最初の出発日。**出発88日前〜0日前の完全な系列**が12本 |
| 2027-02-13 | 全10日付が完成。出発178日前までの形が確定 |

**遡りで見えるのは遠い側だけ**である点に注意。谷（50〜59日前）と
値上がり（30日前以降）は出発日が近づくのを待つ必要がある。

## 測るもの

1. **谷の位置と深さ。** 片道の 50〜59日前 / −4.2% と一致するか
2. **滞在日数が効くか。** 7泊と14泊で曲線が違うか。違うなら
   `sweet_spot` を滞在日数の関数にする必要がある
3. **復路の曜日が効くか。** 10泊（曜日が変わる）と 7/14泊（変わらない）の差
4. **遅延の罰。** 出発30日前以降の +16.7% が往復でも同じか
5. **片道との直接比較。** SAN-HND / SAN-NRT で、同じ出発日の片道系列と
   往復系列を並べる

## 交絡として承知していること

- **年末年始が入る。** 出発 2026-12-25 の10泊は復路 2027-01-04。繁忙期の
  効果と滞在日数の効果が混ざる日付がある（課題3と同根）
- **区間が米西海岸⇄東京に偏っている**（課題11）。片道調査と同じ偏り
- **復路の便は分からない。** 価格は往復合計だが、応答に入るのは往路の
  セグメントだけ（取得元の都合、`round-trip-plan.md` 1.2）

## 容量への影響

| | 前 | 後 |
|---|---|---|
| 稼働ルート | 331 / 1000 | **451 / 1000（45%）** |
| 収集時間（推定） | 63 分 | **約 86 分** |

日次ジョブは 03:00 PT 開始。86分でも余裕がある。

`purpose='research'` なので KPI の需要・定着の列には数えない
（`watches_research` に件数が出る）。容量には数える。

## 再現

```bash
python -m app.cli add-research-monitors \
    --routes SAN-HND,SAN-NRT,LAX-HND,LAX-NRT \
    --from-days 88 --to-days 178 --count 10 --stay-nights 7,10,14
python -m app.cli backfill-history
```
